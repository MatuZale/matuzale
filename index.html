    Decomposition test for positive maps

    A repository containing test on the decomposability of positive maps in finite-dimensional matrix algebras.

    This project contains two semidefinite-programming based tools written in MATLAB/CVX for the analysis of positive maps and entanglement properties of quantum states.

    • Choi matrix SDP decomposition (sdp_decomp.m)
      Given a Choi matrix of a linear map, this routine sets up and solves a semidefinite program to decompose it into positive parts: it searches for positive semidefinite matrices P and Q such that the difference between the given Choi matrix and the combination P + PartialTranspose(Q) is minimized in trace norm (via auxiliary PSD slack variables Ptt and Qtt). The optimal objective value dec = trace(Ptt + Qtt) quantifies how well the Choi matrix can be represented in this structured form and can be used as a numerical indicator of (non-)decomposability of the underlying map.
    • PPT entangled state construction via SDP (SDP_PPT.m)
      Based on the method from arXiv:1708.06595, this function implements an SDP-based procedure to identify PPT entangled states using the antisymmetric subspace:
      • Constructs the antisymmetric and symmetric projectors PA, PS on a bipartite d × d system.
      • Generates a random density matrix and normalizes its projection onto the antisymmetric subspace to obtain an antisymmetric state ρA.
      • Solves an SDP over states σ that are positive, normalized, and PPT (positive under partial transpose), maximizing the overlap Tr(PA σ) under the constraint PA σ PA = Tr(PA σ) · ρA.
      • Returns the optimal overlap pPPT, the optimal PPT state σ*, and the value of the realignment criterion ∑ svd(Realignment(σ*)), which helps assess whether σ* is entangled.
      If pPPT(ρA) < 1/2, the resulting optimal PPT state σ* is a PPT entangled state, providing an explicit numerical example of bound entanglement.

    Together, these tools illustrate how convex optimization and representation theory can be used to study positive maps, decomposability, and PPT entanglement in finite-dimensional quantum information theory.

    Y-Y Basis in matrix algebra

    A repository containing research on the Young-Yamanouchi basis and its applications in quantum information theory.

    This program builds the representation-theoretic block structure of the permutation action on a tensor power of a finite-dimensional quantum system. For a fixed local dimension d and number of parties N, it:

    • Generates all Young diagrams (partitions) of N - 1 with at most d rows.
    • Uses Sage to compute the dimension of the corresponding irreducible SN-1 representations (via standard tableaux) and their multiplicities in the tensor space (via semistandard tableaux).
    • Constructs the orthogonal representation matrices of the symmetric group and the associated permutation operators on (ℂd)⊗(N-1).
    • Assembles operator blocks Eij(μ) that encode the projectors and intertwiners onto each irreducible subspace.

    The output is a dictionary of operators that explicitly realizes the Young diagram / Schur–Weyl decomposition of the permutation representation on the tensor product space, together with the associated dimensions and multiplicities. This structure is useful in representation-theoretic approaches to quantum information, for example in port-based teleportation and symmetric channel analysis.

    Strange Attractors

    A repository containing a generator on color recursive maps/fractals.

    This program generates high-resolution animations of the Clifford attractor, a nonlinear chaotic system known for producing intricate geometric structures. The animation evolves smoothly over time by dynamically varying one of the attractor parameters.

    • Uses Numba-optimized Clifford map iteration to compute tens of thousands of chaotic trajectories efficiently.
    • Accumulates points into a 2D density histogram instead of plotting them directly, producing smooth, high-detail structures.
    • Applies logarithmic density scaling and a custom neon colormap to reveal fine fractal features and achieve a glowing visual effect.
    • Animates parameter a(t) over time, causing the attractor to morph between different chaotic geometries, creating fluid, organic motion.
    • Uses Matplotlib FuncAnimation to render each frame and FFmpeg to export the final animation as a high-quality MP4 video.
    • Includes a quick test_single_frame() function to preview the attractor before generating the full animation.

    The result is a smooth, neon-styled visualization of chaotic dynamics, suitable for artistic animations, mathematical demonstrations, or generative-art experiments.

    Email automatisation

    An automation system that processes incoming emails with invoices and payment confirmations, extracts structured data from PDF attachments, and updates property accounting sheets.

    This project implements a fully automated pipeline for handling property-related accounting via email. It continuously monitors an inbox, extracts data from received invoices, detects payment confirmations, and synchronizes everything with Google Sheets.

    • Automated email processing
      The system scans incoming messages, identifies relevant ones (invoices, settlements, statements, confirmations), downloads their attachments, and extracts all text content usable for bookkeeping.
    • Robust PDF analysis
      Attached invoices and settlement documents are analyzed to extract:
      • property address,
      • amount due or outstanding balance,
      • payment deadline,
      • invoice/statement identifiers,
      • document type (invoice, settlement, statement, notice).
      The parser supports many real-world formats and uses multiple pattern layers to reliably detect information across heterogeneous documents.
    • Google Sheets synchronization
      Each invoice is automatically assigned to the proper sheet tab based on the address. A rolling summary row keeps track of totals and outstanding balances.
    • Automatic payment confirmation
      The system detects confirmation emails (plain text, HTML, or forwarded), extracts the relevant amount or referenced invoice, and marks the corresponding entry in Google Sheets as paid. This works even when multiple invoices exist for the same property in one month.
    • Web control panel
      A lightweight web interface provides:
      • manual “check emails now” trigger,
      • real-time logs of the automation,
      • a preview of recent data pulled from Google Sheets,
      • basic filtering for easier debugging.

    The project integrates email parsing, PDF text extraction, data normalization, and spreadsheet automation to create a fully hands-off accounting assistant for managing multiple rental properties.
