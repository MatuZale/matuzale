# 🌐 Personal Portfolio — Tomasz Młynik

This is my personal portfolio website built with **HTML, CSS and JavaScript**, showcasing my research background, publications, projects, skills, and contact information.

🔗 **Live Demo:**  
https://matuzale.github.io  
(or your custom domain once configured)

---

## 🚀 Features

- Fully responsive personal portfolio
- Light/Dark mode toggle with localStorage
- Smooth navigation with anchors
- Mobile-friendly navigation (hamburger)
- Separate sections for:
  - About Me
  - Experience
  - Projects
  - Publications (with links to Google Scholar & arXiv)
  - Contact Info
- Clean card-based layout
- Custom icons and assets
- Fully deployed on GitHub Pages
